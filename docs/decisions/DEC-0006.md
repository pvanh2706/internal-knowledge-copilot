# DEC-0006 — Centralized Authorization and Revalidation

**Category:** Security & Retrieval Architecture  
**Decision status:** APPROVED  
**Documentation status:** PO-approved content; Publication PR pending merge  
**Decision authority:** Product Owner  
**Approved on:** 2026-10-29  
**Implementation authorization:** NOT AUTHORIZED

## Context

AR-B-02: AI Q&A, Workflow Copilot, Action Approvals sử dụng kiểm tra quyền không đồng nhất. Một số nhánh xử lý không có external object/connector hoặc dựa vào ACL snapshot, làm tăng security drift giữa module.

## Options Considered

- **Option A:** Từng module tự kiểm tra quyền độc lập.
- **Option B:** Dùng chung policy enforcement và permission revalidation boundaries.

## Decision

**Chọn Option B.**

- Các đường AI Q&A, Workflow Recommendation và external context dùng chung authorization abstraction.
- Mỗi nguồn trước khi vào AI prompt/citation phải recheck quyền và current source status.
- Vector metadata không thể tự quyết định quyền; external source system giữ thẩm quyền.
- Nếu thiếu permission proof, áp dụng fail-closed DEC-0004.
- Cache TTL, source fallback và APIs phải được thiết kế chi tiết và duyệt riêng trong S02.

## Rationale

- Thống nhất enforcement, giảm rủi ro rò rỉ tri thức và dễ viết security regression tests.

## Consequences and Trade-offs

- Có thể tăng latency và source API load; optimizations chỉ hợp lệ nếu không làm yếu quyền.
- SEC-03 và SEC-04 vẫn OPEN.
